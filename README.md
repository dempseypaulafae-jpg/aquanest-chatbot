# AquaNest Filters Support Bot

This is a simple rule-based customer service chatbot for a fictitious company called AquaNest Filters.

## Files

- `index.html` — page structure and chatbot layout
- `style.css` — styling for the page and chat window
- `script.js` — chatbot logic and response rules

## How to publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload these four files into the root of the repository.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/root`, then save.
6. Wait a few minutes for GitHub Pages to publish the site.

## Notes

This is a front-end demo only. It does not use a private API key or a live AI model. Do not put API keys into browser JavaScript files.
